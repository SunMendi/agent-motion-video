# Reusable video prompts

The maintained intake prompt is in [start.md](start.md). Creative rules are in [audio-to-visual-director.md](audio-to-visual-director.md); production order is in [workflow.md](workflow.md). Use those files rather than maintaining a second set of design rules here.

## Setup when requested

> Read AGENTS.md and setup.md. Inspect installed tools. Install only missing or incompatible requirements when authorized. Complete setup checks and report actual results.

## Start a video (Autonomous End-to-End)

> Follow the agent prompt in start.md. My audio: [path or URL]. My outcome: [outcome]. My audience: [audience]. Choose visual direction, build storyboard, implement scenes, run production checks, render complete video, verify 9:16 aspect ratio and loudness, and export the final video autonomously without stopping for manual approval checkpoints.

## Start another video

> Start a new video in this project. Follow reset.md. Inspect the reset preview, preserve exports and shared tools, and reset only the active-video boundary. Prepare to receive new inputs.
