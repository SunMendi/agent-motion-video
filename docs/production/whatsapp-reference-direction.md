## Why our previous outputs missed this

The renderer already supports the core techniques visible here: separately positioned objects, vector shapes, masks, opacity, scale, movement, and frame-derived transitions. The primary failure is creative selection and execution.

Our direction repeatedly described trust boundaries, system states, authentic-looking interfaces, and technical mechanisms. The worker interpreted that as a set of labelled dashboards. My earlier brief also encouraged spreading objects across the stage. That produced three separated horizontal panels instead of a clear visual hierarchy. Additional schema fields and passing reviews did not supply art direction.

The worker then used scans, counters, pulses, and blinking cursors to meet motion checks. The reference instead changes the viewer's understanding: an option is rejected, a better comparison appears, a selected price changes. Those are staged operations with an endpoint. A resolved scene can then hold.

Asset choice also matters. The reference uses recognizable cup, watch, and shirt artwork. Our many text cards require reading before their subjects can be understood. Collect or author polished subject assets first; use independently controlled layers where an operation needs them. A model identity can use genuine publisher/product artwork and a short exact name. Do not replace it with an invented official dossier or pretend a hand-drawn mark is sourced.

## Worker design contract for this reference

Use a clean illustrated explainer treatment. Put the narration in top captions. In the body, start with one hero subject or a small comparison group. Add a short title only when it helps orientation. Keep necessary names, quantities, comparison labels, or a short result. Remove parallel explanatory sentences, status chips, invented trial counts, packet metadata, and persistent summary footers.

Choose one clear operation for the current meaning beat: reveal, compare, reject, select, transfer, split, conceal, replace, disconnect, or contain. Build the scene around that operation. An actual mechanism can use a focused diagram, but technical vocabulary in the voice does not require a full infrastructure schematic.

Choose a coherent illustration and motion vocabulary. For this reference, useful starting behaviors are staggered subject entry, a brief directional reveal, lift/outline for emphasis, dimming of the rejected option, meaningful value replacement, and a broad section wipe. Define a common accent palette and shadow treatment for the current recording. Do not prescribe a new spring for every object or run decorative effects continuously. Use eased, frame-derived movement and readable settles.

Recompose as the explanation develops. A large single subject can shrink or move to admit a second subject. A selected object can grow while alternatives leave. A message can become an envelope and travel to its recipient. The composition should remain readable with captions covered. Then review it with captions visible to ensure they do not compete.

The shared action stage is a safe working region, not a requirement to occupy every row. Use fewer larger subjects, with margins that support them. Avoid the repeated header/body/footer panel arrangement. Let the scale of the main subject and type establish hierarchy.

## Applying the visual grammar to the current AI narration

- **Identity:** establish a recognizable model/publisher identity and short name, then let the presented account change while its real origin remains understandable. Use a few large objects.
- **Contribution:** show a clean file or patch object. Reveal a short disputed fragment at its voice anchor, then move the contribution toward pending review. A complete GitHub dashboard is unnecessary.
- **Concealment:** carry the same message through a few relays, then present its claimed identity and finish delivery. Keep route labels minimal.
- **Second identity:** split another account from the same origin; show it supporting the original contribution. Make the shared origin the visual reveal.
- **Persistence:** show the warning and continued attempt, then the narrated proportion as a large essential figure. Treat it as a sourced or explicitly uncertain narrated claim, without fabricated trial telemetry.
- **Sandbox:** show one enclosure, a controlled opening, and a request crossing it. The outside region and later closure provide the explanation.
- **Cache:** use two endpoints and one shared cache state. Show an operation changing that state and a delayed response at the other endpoint. Use only a necessary delay indicator, not an invented nanosecond measurement or eight-bank console.
- **Disconnection:** separate the actual connection and close a boundary around the same retained objects. Show the consequence after the action.

These examples translate the reference's simplicity and staged meaning. They do not import its products, pricing claims, or exact scene durations into the AI video.
